# 第五阶段交付审计：中文界面与免安装试用包

日期：2026-10-27（工作跨过北京时间午夜）。用户授权直接推进到可见软件，不再逐阶段确认。

1. 目标与结果：提供可解压运行的中文Windows x64软件；实现本机检查、路径对比、残留代理计划/恢复界面与说明。不是完整自动修复成品，真实Agent与TUN业务验收尚未完成。
2. 完成内容：四页WPF窗口、居中恢复窗口、差异/恢复状态、检查同意门禁、操作中关闭保护；WinINet当前用户配置只读查询；静态本机残留代理计划与模拟写入/回滚逻辑；自包含ZIP与文件清单。
3. 关键决策：原生系统代理写入与回滚默认硬锁，不给用户提供运行时跳过开关。实验提示不代替隔离Windows验收。未知真实Agent版本仍只读。
4. 依据：沿用批准的R3作用域，使用Windows受支持的WinINet连接选项与刷新通知。只改相关flags，保留地址/绕过/PAC等上下文；Windows设置不提供与外部应用之间的原子CAS，不能宣称零竞态。
5. 开源调查：延续既有六项目调查后自研小核心的路线；本次使用.NET、WinINet标准能力，没有复制第三方候选代码或引入新的NuGet库。官方依据见下。
6. 修改范围：Core/Repair/ManualProxyRepair、Windows/Repair/WindowsManualProxySettings、App窗口、Unit/Integration测试、打包脚本及文档；只重排原有界面，保留现有检查/导出，不更换技术栈。
7. 依赖：无新增/删除/升级NuGet开发依赖；交付包新增随附.NET运行时10.0.11，完整许可证随包。包为win-x64、0.1.0-preview.1、无签名；不购买证书或绕过安全提示。
8. 数据接口：新增版本1残留代理计划/受保护恢复记录、2分钟计划过期、精确摘要确认；无数据库变化。恢复数据只在当前用户独立目录，不提交原始记录。
9. 验证：Release单元59/59、集成23/23；原生查询实际运行；发布门禁实际拒绝真实写入口。完整Windows写入没有执行。源码卫生、格式、构建结果另见验证记录。
10. 包验证：自包含发布成功；ZIP解压后483个文件逐一SHA256通过；设置无效DOTNET_ROOT与关闭多级查找后短时入口仍以预期2退出，runtimeconfig包含两个10.0.11运行时。不是干净机证明。
11. GUI验证：实际打开源码构建及最终自包含包；完成只读本机检查，检查/探测/修复/说明页面可见；最终恢复弹窗明确显示未解锁，未勾选本机端口同意时点击检查显示先确认范围。没有切换VPN、联网探测、写入系统或调用模型。
12. 审查与修复：审查发现未验收原生写入曾以实验功能暴露，以及异常处理再次读取坏目录可能逃出async void。前者新增Release门禁用例先失败后通过，并在后端硬锁/UI禁用；后者历史刷新独立捕获错误。未把独立审查等同测试。
13. 安全与性能：只接受静态回环数字IP，拒绝凭据、远程代理、协议分流、PAC/自动发现及策略不确定；超时不作为拒绝连接。文件保留/备份策略沿用，恢复记录200条上限不自动清理。无性能基准；自包含包更大但无需安装SDK。
14. 已知限制与目标差距：系统代理写入/通知/回滚未在隔离Windows验收；真实Agent的配置覆盖链/可信身份/单实例机制、有效路由与DNS分阶段、业务/TUN正常退出、其他Windows、干净安装均未完成。没有GitHub上传或正式发布；不能承诺6个月优惠获批。
15. 后续优先级：P0隔离Windows真实写入与各Agent机制验证；P1解锁逐版本UI及真实XSUS TUN正常退出跨Agent验收；P2干净机、签名选择、GitHub目标核对与发布。当前交付用于直接查看与只读诊断，不把未测能力标绿。
