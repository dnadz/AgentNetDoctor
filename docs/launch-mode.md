# 短时启动入口（开发阶段）

当前没有真实Agent启动注册，也没有在UI开放创建配置。本页描述已实现的内部约定，不能据此手工配置任意程序。

调用格式：`AgentNetDoctor.App.exe --launch <profile-id>`。ID必须为32位十六进制，不是文件路径。读取位置固定为当前用户LocalAppData下AgentNetDoctor/launch-profiles；配置由CurrentUser DPAPI保护。加载失败不回退到明文或任意外部计划。

| 退出码 | 意义 |
|---|---|
| 0 | 目标已启动，业务连通性尚未验证 |
| 2 | 参数无效 |
| 3 | 目标/版本/模式/指纹拒绝，或创建进程失败 |
| 4 | 请保存工作并正常退出已有目标，再重试 |
| 5 | 配置读取、保护或结构验证失败 |

直连环境模式只清除目标子进程代理变量，不修改Windows或VPN，不代表绕过TUN。显式HTTP模式只对该子进程设置HTTP_PROXY与HTTPS_PROXY。应用可能另有网络配置或忽略变量，必须验证实际版本后才允许注册。

软件启动目标后即退出，不建立后台守护。无参数启动仍为中文只读交互窗口。
