# 简单模式界面交付（preview.4）

2026-10-27。用户指出旧“连接对比”不可用、专业选项太多，要求普通用户能用，并允许删除无用入口。

## 目标、原因与实际行为

截图控件被禁用源于旧页要求先完成本机检查，界面未在入口处明确指导，不是已经证明网络探针失效。本轮移除独立“连接对比”页、重复旧探测事件和默认界面未开放的修复入口，保留底层有效检测。主页收敛为选软件→开始检查；打开软件检查窗口后自动一次本机检查，结果用白话说明发现和下一步。

网址、代理、主动服务测试、技术报告和电脑整体清单置于默认收起的高级区域。普通流程不要求知道服务器根地址或端口。没有擅自填官网假装业务入口；服务没有测试就明确不代表服务器/账号/业务正常。未知身份也不标成“未安装”。

## 工程范围与决策

- 沿用WPF、采集器、探针与原有分层，修改MainWindow和ToolNetworkWindow呈现/编排，新增Core/SimpleNetworkSummary。旧独立Probe_Click及其控件删除，服务对比仍由高级工具保留。
- 未开放系统代理修复从公开入口移除，底层保护/备份代码与测试保留；没有删除用户数据或扩大任何网络写入权限。
- 自动检查的Loaded一次解绑并有运行中防重入；操作期间锁住选择与冲突操作，取消/失败显示不完整，不宣称网络正常。主动服务测试仍需要确认与点击。
- 无新增、删除或升级NuGet依赖；不更换框架、架构或公共数据schema，无数据库变化。复用原有组件，不涉及新的开源方案选择，不为界面维护重复搜索GitHub。
- UI采用原有蓝绿/浅灰配色与系统中文字体，强化唯一主要按钮与结果，技术信息按需展开，不展示尚不能执行的“修复”按钮。

## 验证与审查

旧窗口在新流程约束下实际失败（缺HomeToolBox/折叠区，仍含ProbeControls）；实现后主页、21个软件窗口资源构造及高级区默认折叠通过。白话摘要单元验证本机检查不宣称服务健康、未知不称未安装、代理认证与端口拒绝给不同下一步。Release单元69项、集成29项通过，Release构建0警告0错误。格式、源码边界、成品GUI与包校验见verification.md。

独立只读审查未发现可证实新增P1/P2，确认自动检查解绑/防重入、取消/失败未知、服务测试同意门禁及旧入口移除。审查者未运行测试或访问真实网络，不把审查代替运行验证。

## 隐私、性能、兼容与差距

底层读取/本机回环端口检查与以前相同；普通检查不会主动请求公网或调用模型，没有修改Windows/Agent配置。界面重排无已知显著性能改变，未做性能基准。仍只在当前Windows开发机验证；没有宣称普通用户实测、其他Windows、业务/TUN时序或真实自动修复已完成。

本轮完成易用性与功能入口整理，不等于原项目自动网络优化目标完成。P0依旧为隔离Windows和真实Agent机制/修改回滚验收；P1普通用户实际使用反馈与真实业务验证；P2其他平台、签名与发布。未上传GitHub。
