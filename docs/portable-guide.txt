Agent 网络医生 · 简单模式（0.1 preview.4）

怎么打开
解压整个压缩包，双击 AgentNetDoctor.App.exe。不要只复制一个文件。
不需要安装其他运行环境，也不需要以管理员身份打开。

怎么用
1. 先正常打开连不上的软件。
2. 在网络医生中选中它，点击“开始检查”。
3. 等待结果，阅读“发现了什么”和“下一步”。需要时点“重新检查”。
普通检查不需要填写网址、端口或代理地址，不会自动修改你的网络。

高级选项
一般不需要打开。熟悉电脑的人可用它继续测试真实服务地址、比较已有代理路径、查看或保存技术报告。
附加服务测试只有在确认范围并点击按钮后才联网，不发送登录信息、不调用模型。
没有填写服务地址时，只完成电脑端检查，不能证明软件服务器、登录或发送消息正常。
原来单独的“连接对比”页面已移除，相关能力合并到软件检查的高级选项。
尚未开放的系统代理修复/回滚不再作为普通用户入口展示；本版不自动修复配置。

检查范围
Antigravity、AnythingLLM、Chatbox、Cursor、DeepSeek Harness、GitHub Copilot、GitHub Desktop、Google Cloud SDK Shell、Grok Bot、Obsidian、Ollama、Qoder、QoderWake、TRAE CN、TRAE Work CN、Visual Studio Code、WorkBuddy、豆包、ChatGPT、Claude桌面版、Codex。
没有取得运行信息不等于没有安装；商店版、便携版、插件或后台进程可能暂时无法完整识别。

隐私与退出
普通检查读取本机设置和软件连接，也会测试明确配置的本机代理入口，不访问公网。
不发送API Key、订阅或聊天记录，不更换模型提供商。分享报告前请检查内容。
没有常驻服务、自启动或托盘。关闭软件后不会继续接管网络。
先关闭软件，再删除解压出来的文件夹即可移除程序；你自行保存的报告不会被删除。

当前限制
本版提供诊断和建议，不保证所有软件或VPN组合都能自动恢复。
没有执行代理、DNS、路由或VPN规则改写；真实业务及正常退出VPN后的组合验收尚未完成。
Windows x64自包含包，仅在当前Windows 11开发机验证，未完成其他Windows或干净机验收。
本包未签名，不自动绕过Windows安全提示。
