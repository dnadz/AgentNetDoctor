# 21软件独立网络诊断（preview.3）

2026-10-27。用户要求“这些也要检查优化网络，不是只加名字”。目标是21项实际网络检查和证据驱动的优化；自动写入目标尚未完成，本版实现独立诊断及调整步骤，不能宣称21款已经自动优化。

## 已实现的实际检查

软件清单选一项，点击“检查并优化所选软件网络”。21项共用采集/协议实现，产品特定步骤各自定义，不复制21套探针。

- 重新采集本机状态；按软件候选进程的PID、启动时间、路径关联TCP，展示本地/远端地址和状态，不将其他PID或已重用PID当成本软件。
- 读取Windows手动代理/PAC/自动发现；当前检查程序的进程环境、用户环境、机器环境分别报告，明确不代表目标进程实际继承。只允许代理相关变量，不读取目标进程内存或凭据。
- VS Code、Cursor、Qoder、TRAE CN、TRAE Work CN、Antigravity的候选用户settings.json按已知VS Code字段白名单读取；缺失、权限、重解析点等保持未知。不能把候选路径或语法可解析当作版本能力验证。其他产品未知数据库不扫描。
- 对符合条件的静态系统/应用候选回环代理端口做真实TCP检查，失败与超时未知分开；接受TCP不等于HTTP代理协议或认证可用。不接触远程代理端口。
- 用户指定实际服务根地址并确认后，执行系统DNS、无显式代理TCP、无认证GET；可比对指定HTTP代理。HTTPS保持系统证书校验，TLS错误来自HTTP结果，不提供虚构的独立TLS耗时。
- 本机Ollama默认使用只读/api/version，不调用模型，不测试/generate/chat。回环目标不发送给远端代理。其他产品不默认用官网作为业务探针，要求其真实入口。

## 优化含义与边界

根据端口状态、同一快照/同一服务的路径结果生成软件特定调整步骤。只有2xx路径结果参与正向切换建议；407明确代理认证未完成，不推荐据此切换；单路径不说两条均失败；本机服务不推荐远端代理。GitHub Desktop区分API/Git HTTPS/SSH，编辑器区分宿主/扩展/终端，Ollama区分本地推理/下载，聊天工作台区分实际模型提供商；不更换提供商或Key。

这是可执行检查和优化方案生成，不是已执行自动配置修改。真实版本、身份、应用覆盖链与回滚机制未验收的字段不会写入；系统代理写入口仍硬锁。本机没有WindowsSandbox.exe入口，尚无可用的已验证隔离Windows写入环境；不因此拿工作网络做破坏性验证。

## 决策、复用与改动范围

沿用已有Core/Windows/Adapters/WPF架构，复用SnapshotCollector、ConfigurationFileReader、ProbeRunner、脱敏与打包。新增ToolNetworkAnalyzer、NetworkStages、ToolConfigurationCandidates、ToolNetworkWindow；TCP模型添加可空远端地址/端口，旧构造兼容，没有数据库变化。无新增/删除/升级NuGet依赖，没有新增云服务或费用。官方核对[VS Code网络](https://code.visualstudio.com/docs/setup/network)、[Cursor网络](https://prod.cursor.com/docs/enterprise/network-configuration)、[Ollama环境配置源码](https://github.com/ollama/ollama/blob/main/envconfig/config.go)；不复制候选项目代码，仍为自研小核心+平台组件。

## 审查与验证

分析器最初2例有效失败后实现；不同服务错误配对的回归先失败后修正；407与本机目标错误推荐的2例先失败后修正。单元67项通过；新增真实回环DNS/TCP及URL边界5例通过，全部21个独立窗口资源构造通过。完整集成、GUI、格式、包校验结果见verification.md。

独立审查指出取消后可能混合新快照与旧配置：改为先清旧数据，局部变量收齐并检查取消后才统一提交，失败不开放探测。此取消交错修复是代码检查，未做可控中断注入；不把它包装成已通过的运行回归。未请求公网或执行真实Agent业务，不宣称TUN退出已验收。

性能：一个目标DNS/TCP各4秒超时，HTTP各12秒；本机代理最多4项、每项2秒，仅用户点击后执行，无常驻监听。没有吞吐/性能基准。只使用当前用户权限；结果出口脱敏，导出须选路径。软件进程仍可能漏掉共享宿主/后台进程，TCP非原子；探针不保证重现客户端HTTP版本、SNI、认证与流式协议。

P0仍是隔离Windows与逐客户端实际代理机制/写入回滚验收；P1连接已验证的配置修复并测试真实业务与XSUS正常退出；P2补共享宿主/商店/便携发现、性能与干净机。没有上传GitHub或正式发布。修改范围、依赖、数据、安全、兼容与目标差距均以上述证据为准。
