# Agent 网络医生 · Mac中文预览版

中文简单模式：选软件→开始检查→看白话结果和下一步。默认只检查本机，服务探测需要在高级选项主动同意；不调用模型，不自动修改系统/Agent设置。

分别下载osx-arm64（Apple Silicon）或osx-x64（Intel）ZIP，完整解压后打开AgentNetDoctor.app。目标macOS14+，没有宣称所有版本兼容。各ZIP附SHA256，目录内附逐文件清单、说明及第三方许可。

实际采集当前权限可见的系统代理/PAC、进程候选、TCP和网卡/DNS配置；支持实际服务的DNS/TCP/HTTPS及指定HTTP代理路径测试。21项原有清单保留，Mac发行/形态未核实者明确未知；共享宿主、应用私有代理和真实业务不能靠这些观察确认。

仅有ad-hoc临时签名，没有Apple Developer ID签名或公证，首次打开可能被系统阻止；不提供关闭系统安全保护的方案。GitHub Mac机器上的测试/采集/包检查不等于真实桌面交互或目标Agent/VPN业务验收。请按预览版评估。
