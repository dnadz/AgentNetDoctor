Agent 网络医生 · 中文Mac预览版

1. 下载与你电脑匹配的ZIP：Apple Silicon（M系列芯片）选osx-arm64，Intel选osx-x64。
2. 完整解压，打开AgentNetDoctor.app。目标macOS14及以后；实际兼容以测试记录为准。
3. 先正常打开连接有问题的软件，选择软件名称，点击“开始检查”，阅读白话结果和下一步。
4. 普通检查不要求网址/端口，不请求公网，不读取密钥、聊天或Agent私有配置。仅对明确配置的数字回环代理入口做本机连接检查。
5. 高级选项可填写实际HTTPS服务根地址并主动同意测试，比较无显式代理/你指定的无凭据HTTP代理路径。不会调用付费模型；无显式代理仍可能经过VPN/TUN。
6. 本版是只读检查与建议，不自动修改代理、DNS、路由、VPN或Agent配置。进程/软件识别为候选，不代表签名、安装完整性或业务正常；未识别不表示未安装。部分清单项目的Mac发行仍未核实。
7. 系统代理不能代表各应用设置；本版未验证应用内/工作区/终端覆盖链，DNS配置不证明实际解析和路由。HTTP响应不证明登录、模型或流式业务正常。
8. 报告在你选择的位置保存，可能包含网络地址；分享前检查。未自动上传。关闭应用后不常驻；移除应用不会自动删除你保存的报告。

分发限制：仅临时ad-hoc签名保证包结构完整，不是Apple Developer ID签名或Apple公证。系统可能阻止首次打开。本项目不要求关闭Gatekeeper、不提供绕过系统安全检查的命令；如系统不允许，请停止并等待开发者签名版本，或由开发者在可信Mac环境自行构建验证。

GitHub Mac runner测试、实际只读采集和打包验证不能替代你的Mac桌面交互、真实Agent业务及VPN切换验收。请勿把预览版当作已经解决所有网络故障的产品。
