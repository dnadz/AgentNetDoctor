2. 决策依据：复用现有确认摘要、字段补丁、DPAPI和ACL；Windows独占文件共享防止普通并发访问。不另建后台服务。
3. 开源路线：沿用已调查的自研产品、Tomlyn只读解析路线；本次局部文件存储无需新增开源框架。没有新增、删除或升级依赖。
4. 修改范围：Core修复接口、恢复记录与只读检查；Windows文件存储/日志/路径检查；Unit与Integration测试及工程文档。没有删除功能或改变现有只读UI。
5. 数据接口：内部增加备份绑定、版本1加密日志及随机ID索引；未变更公开报告或数据库。没有从日志注册任意路径的能力。
6. 已运行：Debug单元48/48、集成14/14；Release解决方案构建0警告0错误；dotnet format --verify-no-changes通过。DPAPI集成在正常用户上下文执行。
7. 已验证行为：BOM/JSONC注释/未知字段字节保留，文件回滚，目标版本变化/运行中拒绝，旧指纹拒绝，文件锁冲突，未注册目标拒绝；Prepared/Completed阶段故障注入后读取受保护日志、分类前后状态、冲突时禁止覆盖。

13. 兼容性：仅当前Windows开发机和合成目标验证；干净VM、跨用户恢复、真实Agent、其他Windows版本未验证。
