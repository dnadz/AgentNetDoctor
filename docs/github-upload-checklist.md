# GitHub上传准备

- [ ] 核实连接身份与最终所有者、仓库名、可见性，未确认不创建远端。
- [ ] 审查LICENSE与第三方组件归属；候选项目尚无代码复制。
- [ ] 运行Verify-Source与完整相关测试、Release构建、格式检查。
- [ ] 审查git ls-files以及全部提交历史；ignore不能代替秘密审查。
- [ ] 检查文档只描述实际能力、未知版本禁写、TUN退出未验证。
- [ ] 上传前展示目标URL、文件清单、验证结果与未验证项。
- [ ] 上传后实际核对远端源码和CI，未上传不得声称完成。
- [ ] 自包含包、签名、干净安装/升级/卸载与VPN验收未完成前，不正式发Release。
