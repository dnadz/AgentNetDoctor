# 第四阶段审计：进程中断与短时启动

日期：2026-10-26。目标：验证修复中的实际进程退出，完成计划Task 8的启动基础；整体产品未完成。

1. 实际完成：测试辅助进程在Prepared日志落盘后或写后Completed日志前直接退出；另一个进程重载日志与文件指纹，识别当前状态并验证显式回滚。
2. 启动实现：LaunchProfile只存目标ID、版本、exe指纹、模式和无凭据HTTP代理；可执行文件路径、参数、工作目录、支持模式来自代码拥有的注册表，配置文件不能注册任意命令。
3. 关键依据：复用既有DPAPI/ACL及.NET ProcessStartInfo.Environment、UseShellExecute=false和ArgumentList；只调整子进程代理环境，不写父进程/用户/机器环境。
4. GitHub路线：沿用批准的自研产品及组件复用路线；局部启动实现使用平台标准库，没有新增、删除或升级NuGet依赖。测试辅助项目仅用于验证，不进入产品包。
5. 修改范围：Core/Launch、Windows/Launch、App启动分派、Unit与Integration测试、测试辅助控制台项目、解决方案和文档；无无关重构或功能删除。
6. 数据接口：加密启动配置版本1；保存须匹配预览摘要，读取验证结构与DPAPI；公开入口只接受--launch与32位十六进制随机ID，不接受外部计划路径。
7. 兼容行为：无参数仍打开原只读窗口；短时模式不创建主窗口、不等待目标结束，不建托盘/服务/计划任务。真实版本的注册表仍为空，不能误称真实Agent已支持。
8. 测试：Release单元49/49、集成20/20；Release构建0警告0错误，格式检查通过。包含真实子进程退出2例、环境隔离2例、运行中/指纹/未知目标拒绝、加密配置重载/篡改与确认失配。首次启动器实现前3例功能断言失败，完成后通过；中断辅助进程最初退出0，2例断言失败，接入故障点后通过。
9. 实际入口验证：Release程序使用非法profile-id实际运行退出2；未创建交互窗口，未调用真实Agent。其他短时退出码：0为已启动待业务验证，3为拒绝或失败，4为需正常退出目标，5为配置读取/保护失败。
10. 网络边界：ClearProxyEnvironment清除子进程HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY（大小写变体）；不保证绕过系统代理、TUN或应用配置。显式模式再设置HTTP_PROXY/HTTPS_PROXY，NO_PROXY保持未设置；只有证明该版本语义适合时才能注册。
11. 已知限制：停止状态检查不是跨进程启动事务，其他程序仍可能在最后检查后启动；exe哈希不覆盖全部DLL/资源。目标运行中的代理行为、单实例转发和依赖身份必须逐版本验证，不能仅靠合成启动成功解锁。
12. 安全兼容：不强杀目标，未调用shell/script，不记录认证信息；测试超时只结束自身创建的辅助进程。当前仅Windows开发环境验证；未验证干净VM、跨用户、掉电或系统重启恢复。
13. 性能：启动增加一次exe哈希与DPAPI读取，未进行性能基准。辅助进程不属于发布产品，不声称正式Agent启动耗时。
14. 与目标差距：未新增真实Agent支持或修复UI；R3当前用户残留代理、可信身份、版本覆盖链、有效路由/DNS、真实业务及XSUS TUN正常退出仍待完成。未上传GitHub、未正式发布。
15. 后续：P0真实身份/版本机制与单实例验证；P1接入中文确认/恢复UI、VM与跨Agent/TUN验收；P2安装包与GitHub发布准备。所有真实写入需先呈现可审阅差异。

进程主动Exit跳过操作完成路径并释放句柄，验证的是实际进程中断；不等于内核崩溃、断电或磁盘故障保证。原位写入仍可能留下部分文件，检测冲突后不会自动覆盖。
