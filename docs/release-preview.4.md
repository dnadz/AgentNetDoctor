# Agent 网络医生：中文简单模式试用版

Windows x64免安装程序。下载ZIP后完整解压，双击AgentNetDoctor.App.exe，无需另装.NET。不要在压缩包中直接运行。

选择遇到问题的软件→开始检查→查看白话结果和下一步。支持截图范围的20款软件及Codex，共21项。高级服务测试和完整技术报告默认收起，服务测试需要主动确认。

本版提供检查与建议，尚未开放真实系统或Agent配置自动修复。没有后台守护，不提供VPN服务；无显式代理不能绕过TUN。HTTP回应不证明账户、模型或业务正常。

本地69项单元和29项集成测试曾通过，主页与Codex本机检查已在开发机运行验收。干净Windows、所有软件实际业务及VPN切换时序尚未完整验收。程序未签名。GitHub Actions检查结果以该提交实际运行记录为准。

附ZIP SHA256文件；解压目录包含各文件SHA256清单、中文说明及第三方许可。不要公开上传包含个人路径、网络地址等信息的报告。
